# Soluciones Digitales

Base inicial de la plataforma para perfiles digitales de negocios conectados mediante NFC y QR.

## Arquitectura prevista

- GitHub Pages: frontend y alojamiento.
- Supabase: autenticación, base de datos, almacenamiento y seguridad.
- NFC: únicamente una URL.
- QR: la misma URL.
- Panel cliente: edición del perfil y estadísticas.
- Panel administrador: gestión de todos los clientes.

## Esta versión

Es una base visual y de prueba. Incluye:

- página principal
- perfil de demostración
- panel provisional
- estructura preparada para Supabase

Todavía no incluye usuarios reales, base de datos, estadísticas reales, pagos ni panel privado.

## Subida a GitHub

1. Extrae este ZIP.
2. Entra en el repositorio `SolucionesDigitales`.
3. Pulsa `Add file` → `Upload files`.
4. Sube TODOS los archivos y carpetas del ZIP.
5. Pulsa `Commit changes`.
6. Espera a que GitHub Pages publique.

No introduzcas contraseñas, claves secretas ni datos reales en estos archivos.
